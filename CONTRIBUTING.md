# Contributing to BitChat

## Development Setup

1. Clone the repository
2. Ensure JDK 17 and Android SDK (API 34) are installed
3. Open in Android Studio or VS Code
4. Run `./gradlew build` to verify setup

## Code Style

- Kotlin coding conventions
- Material Design 3 guidelines
- Compose best practices
- Follow the modular architecture

## Commit Convention

Use conventional commits:
- `feat: description` for new features
- `fix: description` for bug fixes
- `test: description` for tests
- `docs: description` for documentation

## Security

- Never commit secrets, keys, or credentials
- Never invent cryptographic algorithms
- Use established libraries for encryption
- Document security implications of changes
